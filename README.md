# We Never Miss — Digital Marketing Agency

Website code for **We Never Miss** (Digital Marketing Agency by Founder Jaskirat Singh).

Open `index.html` in a browser (internet required for Three.js, Google Fonts, and Font CDN).

## Project Files
- `index.html`: Main page markup (Hero, Services, Our Promise, How We Work, Founder details, Contact form, Floating WhatsApp widget).
- `css/style.css`: Gold & dark-themed custom styling, animations, and responsive layout.
- `js/main.js`: 3D Three.js gold logo target assembly, 3D card tilt effects, scroll animations, WhatsApp & Email contact form handlers.
- `founder.jpg`: Photo of founder Jaskirat Singh.
